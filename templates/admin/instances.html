关于 token 注入

token 已可通过 Web 直接填写(type="password" 防止旁观者窥屏,autocomplete 已关闭)。 也可保留服务器端注入路径,以便在没有 Web UI 的环境上操作: 

echo -n '<token>' | sudo /usr/local/bin/set-instance-token <db-path> <instance-name>

注意:Web 提交后 token 会以原始字节进入 api_token_enc 列(未做对称加密)。 部署必须强制 HTTPS,DB 文件及其备份视为敏感凭据,不要推到不信任的位置。
